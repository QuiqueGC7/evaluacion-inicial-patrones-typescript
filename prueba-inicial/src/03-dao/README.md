¿Qué significa DAO?
Data Access Object.

¿Cuál es su responsabilidad principal?
Aislar la lógica del proyecto de la de la base de datos.

¿Qué relación tiene DAO con una base de datos?
Actua como puente para realizar algunas funciones dentro del código.

¿Qué operaciones aparecen habitualmente en un DAO?
Operaciones CRUD (Create, Read, Update, Delete)

¿Qué diferencia existe entre DAO y Repository?
El DAO se centra en la lógica de la base de datos y el repository de la del proyecto.
